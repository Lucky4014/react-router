## Interview Answers

**What is a Single Page Application (SPA)?**
SPA ek aisi web app hai jisme sirf ek HTML file load hoti hai.
Page navigate karte waqt browser reload nahi hota — React Router
JavaScript se content swap karta hai. Fast aur smooth experience milta hai.

**Link vs Anchor tag?**
Anchor tag `<a href="">` se poora page reload hota hai.
React Router ka `<Link to="">` sirf component change karta hai
bina reload ke — SPA ke liye yahi use karte hain.
